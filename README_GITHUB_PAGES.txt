OLIVIA SEAY ARTIST WEBSITE

Paths are root-relative (/styles.css, /assets/...), so this works on Vercel and any custom domain at the site root.
Upload the CONTENTS of this folder to the ROOT of the repository.

artworks.js holds every work. Work page shows all; homepage shows those with a "home" number.
To add an image: put it in /assets and add  image: "/assets/filename.jpg"
