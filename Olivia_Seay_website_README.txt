OLIVIA SEAY ARTIST WEBSITE

This archive contains the editable source for the website.

CONTENTS
- dist/index.html — homepage
- dist/work/index.html — Work page
- dist/about/index.html — About page
- dist/artworks.js — artwork titles, details, and image paths
- dist/site.js — gallery and lightbox behavior
- dist/nav.js — mobile navigation behavior
- dist/*.css — typography and page styling
- dist/assets/ — artwork and portrait images
- .openai/hosting.json — current Sites hosting configuration

To replace or add artwork, update dist/artworks.js and place the corresponding
image files in dist/assets/. The website is plain HTML, CSS, and JavaScript, so
it can later be moved to another static host without conversion.
